# Governance Lens

Proxy-voting demo built by Vinil Polepalli (vinilpolepalli.com) as a project for Pennant (getpennant.ai).

Pulls real DEF 14A proxy ballots (Tesla, Apple, JPMorgan) from SEC EDGAR, applies an editable voting policy rule by rule, and returns FOR / AGAINST / FLAG with the filing fact behind each call. Rules that can't be assessed from extractable facts render as REVIEW instead of guessing.

Static export of a Next.js app. Built with Claude Code.
